# Бизнес-контекст · версия 9

Переработка навигации, состояний работы и чтения по замечаниям от 22 октября 2026 года. Брендинг, Core Components и иллюстрации версии 8 сохранены.

## Куда идти пользователю

| Раздел | Задача | Что внутри |
|---|---|---|
| Обзор | Быстро понять ближайшие приоритеты | Четыре плитки, три вопроса, обновление оценок и запуск анализа периода |
| Ситуации | Найти вопрос и продолжить работу | Состояния, темы, поиск, сортировка, страницы и разбор влияния |
| Новости | Прочитать публикацию | Короткий анонс, издатель, дата и тип; отдельный экран чтения с оригиналом и связью с бизнесом |
| Анализ периода | Проверить динамику на интервале | Выбор дат, вопрос, показатели и возможные закономерности; сохранённые исследования |
| Управление | Изменить входные данные и поведение модуля | Источники и издания, данные компании, настройки модуля, сведения о прототипе |

Разбор ситуации относится к «Ситуациям», чтение — к «Новостям», результат исследования — к «Анализу периода». Страницы управления не подсвечивают «Обзор». Боковая панель отвечает за оболочку банка. Переключатель компании только меняет компанию; профиль и настройки модуля в нём не дублируются.

## Замечания и изменения

| Было непонятно | Что изменено |
|---|---|
| Счётчики выглядели как ссылки в строке | Отдельные белые плитки с одинаковой сеткой, крупным числом и короткой подписью; вся плитка открывает подборку |
| «Ещё» одновременно с троеточием | У кнопки «Ещё» убрана иконка; меню карточек остаются только с троеточием |
| Наблюдение попадало в работу | У ситуации одно состояние работы; выбор наблюдения переводит активную проверку в наблюдение, сохраняя ответственного, дату и заметку |
| Открытие только по заголовку либо отдельной стрелке | Один основной переход по всей карточке. Стрелка обозначает переход; меню действий имеет отдельную область и фокус |
| «События» не выглядели как чтение | Раздел называется «Новости». Карточки с анонсами открывают страницу чтения; аккордеон статьи убран |
| Много пустых полей при добавлении источника | Сначала ссылка и «Заполнить по ссылке», затем найденные сведения для проверки. Есть ручной ввод |
| Настройки, компания и источники разбросаны | Одно подписанное меню «Управление» в шапке модуля |

| Повтор новостей, непонятная сводка и история внизу | Повторный вход в новости убран. У сводки и журнала есть объяснение содержимого |
| Неясна иерархия вкладок | Четыре раздела с разными задачами и корректным активным состоянием; рабочие статусы находятся внутри ситуаций |

## Состояния

«На проверку» — пользователь ещё не начал проверку; «В работе» — активно проверяет; «Наблюдения» — следит без активной проверки; «Отложено» — вернётся позже; «Архив» — выполнено или скрыто. Низкий аналитический приоритет сам по себе не записывает ситуацию в пользовательские наблюдения.

Переходы вынесены в setWorkStatus. Старый массив watch поддерживается для совместимости экспорта, но при смене статуса обновляется вместе с задачей. Состояние задачи имеет приоритет над старой отметкой. Просмотр не означает выполнения. После смены состояния уведомление предлагает открыть соответствующую подборку. Пустое состояние предлагает «Все ситуации», если фильтрами ничего не скрыто.

## Чтение и объём

Список ограничен десятью материалами на страницу. Для выбора видны заголовок, анонс, дата, характер утверждения и издание. Экран чтения ограничен 780 px вместе с внутренними полями; основной текст 18 px / 1.8 на ПК, 17 px / 1.75 на телефоне. Оригинал, обсуждение и действия с материалом находятся после текста. Связанные ситуации отделены и не объявляются доказанным влиянием.

Банковские отчёты по-прежнему показаны кратким изложением прочитанной части, с явной ссылкой на полный оригинал. Прогноз обозначен прогнозом. Демонстрационные материалы не становятся основаниями компании.

Проверен путь: 150 материалов → страница 15 → чтение → возврат на страницу 15. Фильтры, страница и позиция возврата сохраняются в текущем сеансе. Прочитанность фиксируется при выходе из чтения и зависит от версии содержания. Система не заявляет о новом семантическом объединении публикаций: группировка по одинаковым заголовкам из движка сохранена.

## Добавление материала

Ввод ссылки не отправляет запрос на каждый символ. Пользователь нажимает «Заполнить по ссылке» и получает состояние загрузки. Для разрешённых официальных HTML-страниц извлекаются название, текст, издатель/домен, автор и дата при наличии метаданных; характер утверждений определяется предварительно. Отсутствующие автор и дата не выдумываются. Дату нужно уточнить, автора можно оставить пустым. Сам импорт не включает материал в анализ: это отдельное подтверждение после проверки полей.

Автозагрузка ограничена ЦБ, Альфа-Банком, Росстатом и Минфином; PDF и произвольные сайты требуют ручного текста. При ошибке показан понятный текст и ручной путь. В браузерной проверке страница Альфы не ответила серверу: живой успешный импорт этим визитом не подтверждён. Автозаполнение всех опубликованных полей и отсутствие выдуманной даты/автора проверены серверным тестом с контролируемым HTML.

## Сводка и журнал

«Сводка для сохранения» открывает текущие три приоритета и принятые действия, вместе с числом обновлений и событий за день либо неделю. Доступны HTML и печать в PDF. Выбор периода не выдаётся за фильтрацию времени создания всех текущих задач.

«Журнал обновлений» показывает причины и время пересмотра оценок, версии с основаниями, а также последние проверки, в том числе без изменений. История отдельной ситуации остаётся в её разборе.

## Проверка

42 автоматических теста проходят. Дополнены сценарии перевода «в работе → наблюдение → в работе → отложено → выполнено», сохранения деталей задачи, исключения автоматического наблюдения по низкому приоритету и автозаполнения с неполными метаданными.

В браузере проверены меню управления, карточка по области вне текста заголовка, отдельная работа меню, переход в наблюдение с изменением счётчиков, первый шаг добавления и ручной путь, чтение обычного материала, возврат с 15-й страницы, входы в сводку и журнал. На 320 px проверены плитки и подписанное управление; ширина содержимого 305 px при доступной ширине 305 px, горизонтального переполнения нет. Ошибок приложения в консоли по origin предпросмотра нет.

Полная сертификация WCAG/APCA и новые банковские интеграции не заявляются. Ограничения данных, модели и прав из README и предыдущих QA сохраняются. Контекстные предложения банка не менялись: они подписаны, скрываются и не влияют на оценку.
