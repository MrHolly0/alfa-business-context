# PHP-ядро продукта

Здесь Backend создаёт приложение на PHP 8.4 / Symfony 7.4. Сейчас в каталоге только этот план; Composer-проекта и команд запуска ещё нет.

## За что отвечает

- Хранит компании и их бизнес-контекст.
- Проверяет, какие данные доступны пользователю.
- Принимает запрос на анализ и хранит его состояние.
- Передаёт Python необходимые данные и принимает результат.
- Сохраняет проверенный результат и отдаёт его интерфейсу.

Python в соседнем `apps/intelligence` занимается поиском и анализом. Он получает задание через API Core и возвращает результат со ссылками на источники. Напрямую в таблицы Core он не пишет.

## Первая задача Backend

1. Создать Symfony-приложение и закрепить зависимости в `composer.lock`.
2. Добавить простой локальный запуск и проверку доступности.
3. Реализовать сохранение компании, создание задания анализа и чтение его состояния.
4. Согласовать с ML формат задания и результата, а с Frontend — ответы для экрана.
5. Добавить команды запуска и проверки в этот README.

Черновик запросов и примеры — в [contracts](../../contracts/README.md). Их нужно уточнить на общем демонстрационном сценарии перед реализацией.

Подробная целевая схема PHP-модулей, фоновых задач и публикации результата находится в [техническом плане](../../docs/reference/architecture-details.md). Начинать нужно с одного рабочего сценария из [ближайших задач](../../docs/backlog.md).
