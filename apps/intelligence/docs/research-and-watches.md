# Периоды и наблюдение за условиями

Python-модуль считает изменения по предоставленным наблюдениям и проверяет
подтверждённые Core условия наблюдения. Он не хранит пользовательские списки,
не включает и не закрывает наблюдения и не объявляет гипотезу истинной. Core
владеет выбором компании, подтверждением условий, расписанием заданий и статусом
ситуации.

## Условия наблюдения

`intelligence.watches.evaluate_conditions(watches, *, as_of, context_versions,
document_versions, observations)` принимает типизированные snapshots и возвращает
по одному `WatchEvaluation` на условие. Поддерживаются `date_due`,
`metric_threshold`, `context_revision` и `document_revision`.

Для метрики условие задаёт название, единицы, оператор `ge`/`le`/`eq` и конечный
Decimal-порог. Наблюдение должно содержать компанию, метрику, значение, единицу,
время измерения, время получения сервером и хотя бы одну ссылку на источник.
Измерения или получение после `as_of` исключаются. Если актуального сигнала нет
либо единицы не совпадают, результат — `unknown` с вопросом о нужных данных, а не
`not_met`.

Результат `met` содержит `requires_reassessment=true` и
`core_action=request_reassessment`. Это предложение для Core поставить обычное
задание пересмотра с актуальными контекстом и политикой. `unknown` возвращает
`await_data`; `not_met` — `none`. Только Core решает, ставить ли задание, и
обновляет статус. Текстовые `CandidateAssessment.watch_conditions` являются
предложениями модели: их сначала нужно преобразовать в закрытое условие,
проверить основание и подтвердить в Core. Никакие строки модели сами по себе не
исполняются.

## Исследование периода

`intelligence.periods.analyze_period_research(...)` оборачивает
`research.analyze_period` и добавляет список доступных публикаций в периоде.
Публикация передаётся с `event_id`, `revision`, необязательным `event_time`,
`published_at`, `server_received_at`, `source_id`, точным
`document_revision_ref`, заголовком и точной цитатой. Если время события не
указано, используется время публикации. Для исторического режима нельзя
подменять `server_received_at` временем загрузки, текущей датой или датой,
присланной клиентом: публикация без серверного времени получения исключается.

- `mode="as_known"` использует `known_at` одновременно как срез доступности
  публикаций и как предел доступности исправленных наблюдений.
- `mode="retrospective"` использует `evaluated_at` (или текущее серверное время)
  как предел доступности и показывает позднее полученные данные, если они
  доступны на момент оценки.

Численные показатели рассчитываются кодом: выбирается последняя версия
наблюдения, доступная к срезу, и строятся описательные метрики отдельно по
единицам измерения. `coverage.excluded_by_reason` показывает пропуски и причины
исключения временной шкалы. Короткие ряды, сезонность и серийная зависимость не
превращаются в статистическую значимость. Совпадение новости с движением метрики
не устанавливает причинность.

Пример вызова:

```python
from intelligence.periods import analyze_period_research

report = analyze_period_research(
    observations=[{
        "observation_id": "delivery-2026-10-10",
        "metric": "delivery delay",
        "observed_at": "2026-10-10T00:00:00Z",
        "available_at": "2026-10-11T00:00:00Z",
        "value": "6",
        "unit": "days",
        "source_ref": "receipt:delivery-10",
        "revision": 1,
    }],
    period_start="2026-10-01T00:00:00Z",
    period_end="2026-10-31T23:59:59Z",
    known_at="2026-10-20T12:00:00Z",
    mode="as_known",
    publications=[{
        "event_id": "event-1",
        "revision": 1,
        "event_time": "2026-10-10T09:00:00Z",
        "published_at": "2026-10-10T10:00:00Z",
        "server_received_at": "2026-10-10T10:05:00Z",
        "source_id": "news-1",
        "document_revision_ref": "news-1:article-1:1",
        "title": "Публикация о событии",
        "quote": "Точный фрагмент исходного материала.",
    }],
)
```

API показывает timeline и расчётные изменения. Решение о бизнес-публикации,
планировании повтора или отображении пользователю остаётся за Core.
