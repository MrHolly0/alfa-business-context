# Эксперименты с вариантами анализа

Модуль `intelligence.experiments` предоставляет ограниченные роли для ручных экспериментов с настройками анализа. Он не меняет штатный pipeline и не включает сетевые вызовы автоматически.

`AnalystConfig` фиксирует допустимые настройки шаблона `analysis-v2`; дополнительные поля запрещены. `CandidateGenerator()` без модели возвращает встроенные варианты. При явной передаче LLM генератор делает один структурированный вызов, сам назначает ID и принимает только поля аналитической конфигурации. В `training_summary` передавайте агрегаты обучающих кейсов; отложенные проверочные кейсы туда не включайте.

`PairJudge()` в офлайн-режиме сообщает ничью и прямо указывает, что качество не измерялось. С моделью он сравнивает ответы только по контексту и свидетельствам кейса. Идентификаторы модели, трассировки, расходов и конфигурации из ответов удаляются. Оценки модели носят справочный характер. `critic_round` проверяет, что ссылки критики существуют в переданном списке свидетельств.

Для живого вызова нужно явно выбрать разрешённую модель и режим `model` в окружении вызова. Для генератора рекомендуется Qwen, для судьи — GLM; недорогая Gemma подходит для разработки. Используется существующий `LLMService`, без SDK и скрытого переключения модели. `ExperimentLLM` резервирует стоимость в отдельном постоянном scope и затем вызывает общий сервис, который также проверяет глобальный бюджет. Бюджет экспериментов не превышает 20% глобального дневного лимита; CLI по умолчанию задаёт $0.03 USD и максимум 40 вызовов за период. Все роли должны делить один ledger и стабильный scope. Не создавайте новые scopes для обхода ограничений. Неопределённые вызовы сохраняют резерв.

Запуск выбранных проверок:

```sh
cd apps/intelligence
uv run pytest tests/test_experiments.py tests/test_contenders.py
```

В CLI USD и RUB учитываются в отдельных постоянных пулах. Проверка без сети: `python -m intelligence arena budget --config examples/providers.paid.template.json --profile openrouter`. Смена валюты не обнуляет общий счёт соответствующего провайдера.
