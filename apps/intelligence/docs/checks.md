# Проверка реализации · 24 октября 2026

- Python 3.14 на хосте: 111 тестов прошли.
- Docker / Python 3.12: те же 111 тестов прошли, тестовый контейнер без сети и ключей.
- Сквозной `demo`, пять сценариев `evaluate` в baseline, экспорт JSON Schema/OpenAPI и проверка Compose прошли.
- Внутренний API запущен в Docker, `/health` вернул `200`; проверочный контейнер остановлен.
- Проверка авторизации текущего ключа через `/api/v1/key` вернула `200`; значение ключа в вывод и репозиторий не помещалось.
- Бесплатный OpenRouter `google/gemma-4-26b-a4b-it:free`: явный пробный запрос получил HTTP 429, usage не получен. Автоматического повтора и платного fallback не было. Результат `partial`, неопределённость учёта сохранена. Успешный живой анализ и качество модели этим прогоном не подтверждены.

Тесты проверяют ограничения источников/tenant/дат, версии, точные ссылки и hash цитат, отказ от выдуманной позиции банка, бюджет, ограниченную починку ответа, конкурентные повторы, heartbeat/потерю lease и повторную доставку после потери ACK. Модель и Core в тестах подменяются; HTTP, SQLite и проверки формата — настоящие.

Банковские PDF и CSV ещё не предоставлены. Семантическую точность, полноту поиска, полезность для двух компаний/ролей, реальные тарифы и сквозную связь с PHP проверяем отдельно. Учебный набор не заменяет эти измерения.
