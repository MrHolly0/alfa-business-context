# Корпус документов

`intelligence.corpus.CorpusStore(path)` хранит документы, неизменяемые ревизии и фрагменты evidence в SQLite. Используйте постоянный файл, а не `:memory:`. `ingest(document)` принимает контракт `DocumentInput`, сохраняет `tenant_id`, `source_id`, роль источника, canonical URI и даты; URL остаётся метаданными и никогда не загружается. Точное повторное содержимое создаёт ссылку `duplicate_of`, а новая версия существующего canonical URI получает новую ревизию.

Парсер поддерживает `text/plain`, `text/html`, RSS/XML через `defusedxml` и PDF через `pypdf`. Размер текста ограничен 2 млн символов, PDF — 20 МБ и 100 страниц; неподдержанные/повреждённые данные возвращают `ValueError`. Парсер сообщает о PDF без извлекаемого текста как о вероятно сканированном. RSS ограничен 500 материалами; записи из RSS сохраняются отдельными документами с собственной датой публикации и стабильным идентификатором/ссылкой.

`search(...)` выполняет лексический поиск для русского и английского текста. Tenant, список разрешённых source IDs, роль, `as_of` и явные revision refs ограничивают кандидатов до ранжирования. Без указания ревизии доступна только последняя версия документа на выбранное время. Повторные материалы с одинаковым содержимым занимают одно место в выдаче. Цитаты имеют стабильные ID, hash и локатор смещения или страницы, длина цитаты не превышает 1000 символов. `get_evidence(...)` повторно проверяет tenant/source/time scope.

Проверки offline: `PYTHONPATH=apps/intelligence python -m unittest apps.intelligence.tests.test_corpus apps.intelligence.tests.test_parsers -v`.
