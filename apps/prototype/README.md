# Прототип

Это перенесённый интерактивный прототип версии 10.0.0 на React/Core Components и Node Worker. Он работает как локальное демо с правилами и необязательным LLM-шлюзом; не является реализацией целевых банковских API, Python intelligence или PostgreSQL jobs.

Для установки, запуска и команд из корня репозитория используйте [главный README](../../README.md). Основные пути:

- `web/` — UI, локальные сценарии и browser state;
- `worker/` — текущие HTTP endpoints, ограниченный ingest и необязательный модельный цикл;
- `data/` — демонстрационные seed-данные;
- `scripts/` — сборка, валидация и локальный запуск;
- `tests/` — Node test suite;
- `docs/` — исторические продуктовые заметки и снимки дизайна из исходного архива.

Документы и изображения внутри `docs/` сохранены для истории версий 4–10; они не являются актуальной спецификацией MVP. Текущее поведение описано в [аудите прототипа](../../docs/prototype-status.md), а целевые изменения — в [архитектуре](../../docs/architecture.md) и [плане задач](../../docs/backlog.md).

Ограничения данных, источников, модели и безопасности собраны в корневых [`README.md`](../../README.md) и [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md). Не добавляйте сюда полный кейсовый CSV или банковские PDF без отдельного подтверждения доступа и прав.


## Граница с целевой архитектурой

Локальный запуск и npm-команды выше остаются запуском текущего React/Core + Node Worker прототипа. В новом целевом MVP продуктовый документ предлагает Symfony 7.4 / PHP 8.4 modular monolith для бизнес-Core и Python/FastAPI для AI/Data. Symfony HTTP API, CLI workers и scheduler предполагаются частями одного артефакта; Python получает работу через Core API. PostgreSQL разделяется схемами/ролями Core и AI, оригиналы хранятся в объектном хранилище, UI-события идут через Mercure или банковский SSE hub.

Node Worker описывает только текущий прототип, его не следует развивать как целевой Core/BFF. Существующий банковский BFF можно использовать, если этого требует контракт оболочки; отдельный Node BFF не обязателен. Symfony, PHP, Composer и Mercure не входят в зависимости или Compose текущего прототипа. Допуск PHP и точные версии платформы ещё требуют согласования с банком.
