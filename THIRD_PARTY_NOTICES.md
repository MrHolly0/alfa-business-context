Node.js — среда исполнения/сборки, не npm-пакет приложения. Не использовать прежнее утверждение об отсутствии npm-зависимостей. Перед релизом проверьте лицензии полного транзитивного дерева установленной версии, включая отдельные пакеты компонентов Core.

PHP 8.4 / Symfony 7.4, Composer, Python/FastAPI, PostgreSQL, object storage и Mercure описаны как целевые компоненты MVP в продуктовой архитектуре; они не являются установленными зависимостями или исполняемыми сервисами текущего прототипа и не перечисляются как использованные runtime-компоненты. Для них пока нет Composer lockfile или собственного развертывания в Compose. Node Worker остаётся фактическим backend текущего демо.

## Модели и смоделированные интеграции

- Бриф разрешает только Gemma 4 26B A4B, GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct и Kimi-K2.6. Точные provider API IDs не указаны. В текущем прототипе без ключа работают правила; runtime не вызывает внешнюю AI-платформу сам по себе. При явной настройке шлюза выполняется вызов по `LLM_BASE_URL`/`LLM_MODEL`; соответствие `LLM_MODEL` разрешённому model ID должен подтвердить оператор шлюза.
- Текущая переменная `LLM_CASE_MODEL` принимает legacy aliases, не буквальные имена из PDF: `Gemma 4 26B A4B` → `Gemma 4 26B A4B`; `GLM-5.3-Flash` → `GLM 5.3 Flash`; `Qwen3.6 35B A3B` → `Qwen 3.6 35B A3B`; `DeepSeek-V4.1-Flash` → `DeepSeek V4.1 Flash`; `Qwen3-VL-30B-A3B-Instruct` → `Qwen 3 VL 30B A3B`; `Kimi-K2.6` → `Kimi K2.6`. Наличие alias не подтверждает, что выбранный `LLM_MODEL` соответствует разрешённой модели; это требуется сверить отдельно.
- Доступ к SSO Альфа-Бизнеса, отправка менеджеру и автоматическое действие от имени клиента не подключены; не выдавайте mock UI/черновик или локальные ограничения прототипа за банковскую интеграцию.

Python-слой провайдеров в `apps/intelligence` использует только стандартную библиотеку Python 3.12+ (включая SQLite); внешних runtime Python-пакетов нет. OpenAI-compatible HTTP-протокол не означает использование модели OpenAI: разрешены только шесть моделей кейса. OpenRouter и хакатонный шлюз подключаются по отдельным ключам; без явного live-запуска обращения к ним не выполняются. FastAPI и остальные целевые компоненты пока не установлены этим слоем.
