# Ревью и исправления AI/Data

> **Исторический отчёт.** Он описывает проверку и SQLite-хранилище на исходном срезе 24 октября 2026 года. Приведённые в нём числа тестов, команды и persistence-поведение не являются результатом проверки текущего PostgreSQL runtime. Актуальные миграции, роли, тестовый DSN и SQLite import описаны в [руководстве PostgreSQL](postgresql.md).

Проверка от 24 октября 2026 выявила восемь воспроизводимых ошибок на исходном срезе `9013ec6`. Они касались доступа к источникам, конкурентного исполнения и обработки допустимых входов. Исправления ниже проверяют инварианты программы; они не являются оценкой смыслового качества модели.

## Изменения контрактов и кеша

JSON Schema/OpenAPI экспортированы из моделей. Верхняя граница `EventInput.text` увеличена со 100 тысяч до 2 млн символов; это не увеличивает модельный бюджет. Ограниченная модельная проекция не подменяет сохранённый текст и не создаёт новую ложную ревизию. Ограничение покрытия отражается как `event_text_excerpt_only`.

В `ImpactPackage.coverage` добавлены `origin_group_count`, `independence_status` и `independence_basis`. В кандидате доступны `origin_groups` и `independence_status`. Старые поля `independent_origin_groups`/`independent_origins` сохранены для совместимости и считают консервативные группы после устранения точных перепечаток; это **не число доказанных независимых подтверждений**. При `independence_status=unknown` интерфейс должен показывать, что независимость не установлена. Самостоятельность разных редакций или авторов не выводится из домена и сходства текста.

Версия семантики включена в ключ общего пакета: старый пакет с прежним счётом не выдаётся новому разбору. Проверенные цитаты из допустимого кеша извлечения могут переиспользоваться. Старые ответы с тем же request ID остаются неизменными по правилам идемпотентности; новую проверку после обновления запускают с новым request ID.

В том историческом срезе миграции SQLite добавляли токен резервирования API и токен/поколение poll lease под транзакционной проверкой схемы. Текущее PostgreSQL состояние использует версионированные миграции и управляемый импорт; эта строка не описывает его процедуру.

## Неопределённый исход и восстановление

Если процесс умер после возможной отправки extractor-запроса, а ответ не сохранён, следующий запуск не повторяет платный вызов автоматически. Возвращается атрибутированное извлечение без модели с ограничением `extractor_call_outcome_uncertain_no_automatic_retry`. Оператор должен сверить артефакты и журнал провайдера до нового платного эксперимента.

У API неопределённая ошибка после начала работы сохраняет резерв запроса. Автоматическое освобождение допускается только для доказанного отказа до начала. Обычный таймаут не считается таким доказательством. Уже начавшийся HTTP-запрос коллектора может завершиться до проверки отмены; следующий запрос не начинается.

Этапы workflow являются диагностикой, а не полным механизмом возобновления каждого оплаченного ответа. Локальный SQLite и файловые блокировки рассчитаны на процессы с общим диском; многосерверное исполнение требует отдельного хранилища и протокола.

## Проверки

- **352 теста, 11 subtests** — хост Python 3.14 и Docker Python 3.12.14; новых ошибок нет, остаётся предупреждение testclient/httpx.
- **8/8 исходных независимых acceptance tests** прошли отдельно; их штатная версия — `apps/intelligence/tests/test_review_regressions.py`.
- Экспорт схем совпадает с кодом. Демо даёт 2 события и 4 кандидата для двух компаний. Baseline evaluation — 5/5; локальный турнир выполнен без публикации синтетического победителя.
- Веб собран и проверен: `/` и `/healthz` отвечают `200`, `/api/` — ожидаемый `503`. Предыдущий полный веб-прогон — 37 тестов; код интерфейса этим исправлением не менялся.
- Проверены относительные Markdown-ссылки и существование названных тестов. Команды исправлены, текущая документация отделена от архивов.

Команды выше были командами того исторического среза. Для текущего тестового запуска используйте [инструкцию разработки](development.md) и [руководство PostgreSQL](postgresql.md).

Новых модельных вызовов для исправлений не было. Последний подтверждённый суммарный расход OpenRouter — $0.026409489306; разрешённый потолок остаётся $5. Генерация через Альфу не выполнялась из-за неподтверждённых тарифов. [Живой отчёт](ai-live-checks.md) относится к предыдущим прогонам и не выдаётся за повторную модельную оценку нового кода.

## Оставшиеся границы

Настоящие Symfony Core, пользовательские права, публикация и связь с интерфейсом ещё не подключены. Реальные банковские CSV/PDF, тарифы Альфы, разрешения источников и независимая экспертная разметка остаются внешними условиями. Устойчивость смысла ответов, полезность персонализации и улучшение от турнира не доказаны успешными регрессиями.
