# Компоненты и ответственность

В таблице отдельно указано, что команда может запустить сегодня и что ещё предстоит сделать.

| Каталог | За что отвечает | Состояние |
|---|---|---|
| `apps/prototype` | Сохранённый React-интерфейс, Node Worker, демонстрационные данные и правила. | Можно запустить локально; это текущий интерактивный прототип. |
| `apps/intelligence` | Python-адаптеры модельных шлюзов, командная строка и локальный учёт расходов. | Можно запустить и проверить отдельно. Полный поиск, сбор данных и анализ ещё впереди. |
| `apps/core` | Планируемый PHP/Symfony Core: компании, права, задания и опубликованные результаты. | Пока только README с планом; приложения и PHP-команд запуска нет. |
| `contracts` | Примеры и черновики формата обмена между Core и Python, а также пользовательских запросов. | Сверяйте изменения обеих частей с [`contracts/README.md`](../contracts/README.md); это ещё не работающий API. |
| `infra` | Инструкции по локальному запуску и контейнеру прототипа. | Текущая Compose-конфигурация запускает только прототип. |

## Владельцы данных

- Core будет хранить права доступа, компании, их контекст, пользовательские решения, задания и результаты, которые показываются пользователю.
- Python будет собирать разрешённые материалы, сохранять их версии и готовить выводы с указанием оснований.
- Интерфейс показывает данные и передаёт действия пользователя. Проверка доступа относится к Core.

Пока Core не реализован, бизнес-данные новой системы не имеют работающего серверного хранилища. Прототип хранит часть состояния в браузере; Python-адаптер ведёт отдельный локальный журнал вызовов.

Будущие каталоги интерфейса и BFF не создавайте заранее. React сейчас расположен в `apps/prototype`; отдельный BFF понадобится только при согласовании такого требования.
