# Python-адаптеры модельных провайдеров

Это небольшой адаптер на Python 3.12+ для проверки разрешённых модельных шлюзов. Он не реализует AI pipeline, FastAPI worker, интеграцию с Symfony или маршрут `/api/analyze` текущего Node-сервера. Пакет использует только стандартную библиотеку Python.

Разрешённые названия API моделей и адреса шлюзов следуют инструкции по подключению: [документ провайдера](https://docs.google.com/document/d/1ly8GsI_-oPnCQWvtZ4nGevnnDP2MGYIfpn2zOUFxZ_4). Код проверяет модель по allowlist, но это не подтверждает её доступность в конкретном аккаунте, точные тарифы или включённую передачу usage. До реального запуска оператору нужно сверить эти параметры.

## CLI без сети

Из корня репозитория запустите demo:

```sh
PYTHONPATH=apps/intelligence python -m intelligence.llm
```

Или из `apps/intelligence`:

```sh
python -m intelligence.llm
```

Команда не отправляет сетевой запрос и не читает credentials. Её usage и стоимость в USD синтетические и не измеряют списания провайдера. Подкоманда `demo` запускает тот же fixture.

Запустить тот же пример через Docker можно из корня репозитория:

```sh
docker compose run --rm intelligence
```

Для явного live-вызова Docker использует шаблон конфигурации, смонтированный только для чтения как `/config/providers.json`. Собственный файл задаётся переменной `INTELLIGENCE_CONFIG_FILE`. Передайте prompt через stdin; ключ заранее задайте в shell (`OPENROUTER_API_KEY` или `HACKATHON_API_KEY`):

```sh
docker compose run --rm -T intelligence run \
  --config /config/providers.json --profile openrouter \
  --max-input-tokens 8192 --max-output-tokens 512
```

Эта команда читает prompt из stdin, отправляет запрос провайдеру и может повлечь расходы. Docker хранит SQLite-ledger в именованном томе; это отдельный файл от ledger при запуске Python на хосте.

## Профиль для реального вызова

Скопируйте [`apps/intelligence/examples/providers.template.json`](../apps/intelligence/examples/providers.template.json) в локальный приватный JSON-файл. Шаблон задаёт для Gemma `:free` на OpenRouter нулевые тарифы. Эти нули относятся только к проверенному бесплатному маршруту; при выборе платной модели укажите её фактические тарифы. Тарифы хакатонного шлюза оставлены `null`, потому что они неизвестны: до live вызова или сравнения стоимости замените их фактическими неотрицательными значениями в RUB. Загрузчик отвергает `null` и не считает неизвестную стоимость нулевой.

В allowlist входят точные API ID: `google/gemma-4-26b-a4b-it`, `z-ai/glm-5.3-flash`, `qwen/qwen3.6-35b-a3b`, `deepseek/deepseek-v4.1-flash`, `qwen/qwen3-vl-30b-a3b-instruct`, `moonshotai/kimi-k2.6`. Только для Gemma на OpenRouter разрешён суффикс `:free`. Сверьте актуальную доступность модели, адрес шлюза, тарифы и формат usage с владельцем шлюза перед живым тестом.

Шаблон задаёт отдельные бюджеты `alfa-openrouter-dev` в USD и `alfa-hackathon-team` в RUB. Стоимость OpenRouter в USD никогда не переводится в RUB. Дневной локальный лимит профиля хакатона не может быть выше 500 ₽; у профиля OpenRouter отдельный лимит в USD, который задаёт оператор. Только вызовы с теми же локальным SQLite-файлом и `budget_scope` попадают в общий счётчик. Вызовы из другого приложения, другого файла ledger или другого scope в него не входят и могут расходовать тот же внешний ключ.

Установите переменную окружения, указанную в `api_key_env`, для shell, из которого будет запущена команда. CLI не загружает `.env` и не читает ключи из JSON. Не помещайте ключи в конфиг, prompt, аргументы команды, примеры или вывод.

Проверка профиля не читает ключ:

```sh
PYTHONPATH=apps/intelligence python -m intelligence.llm validate --config /path/to/providers.json --profile openrouter
```

Живой вызов выполняется только явной командой `run`. Prompt читается из UTF-8 файла или stdin; ответ и отчёт о расходе выводятся в stdout:

```sh
PYTHONPATH=apps/intelligence python -m intelligence.llm run \
  --config /path/to/providers.json --profile openrouter \
  --input prompt.txt --max-input-tokens 8192 --max-output-tokens 512
```

На одну команду приходится одна попытка провайдера, без скрытых повторов или переключения на другой шлюз. До запроса сервис резервирует стоимость всего заданного входного лимита и полного лимита output-токенов в валюте профиля. `max_input_tokens` — локальная оценка по размеру UTF-8 текста в байтах и фиксированной надбавке на сообщения. Это не токенизатор провайдера и не серверное ограничение контекста. Лимит output передаётся шлюзу.

Стоимость, сообщённая провайдером в валюте профиля, записывается с источником `provider_reported`. Если провайдер не прислал стоимость, а usage содержит числа входных и выходных токенов, сервис рассчитывает тарифную оценку `rate_estimate`. Несовпадение валют не конвертируется и оставляет резерв неопределённым. Если usage отсутствует или неполон, а стоимость не сообщена, резерв помечается как неопределённый, потому что вызов мог быть тарифицирован.

Локальный резерв не может заставить провайдера соблюдать жёсткий денежный предел. Если окончательное списание превышает резерв, оно всё равно записывается, а локальный дневной расход может превысить лимит. После этого остановите дальнейшие вызовы и проверьте отчёт шлюза. Ledger запрещает новые резервы, когда сумма учтённого расхода и незакрытых резервов достигает лимита.

Посмотреть статус локального периода:

```sh
PYTHONPATH=apps/intelligence python -m intelligence.llm budget \
  --config /path/to/providers.json --profile hackathon
```

Период SQLite-ledger меняется в 03:00 по Europe/Moscow. CLI и библиотека при запуске на хосте используют файл `apps/intelligence/.state/llm-budget.sqlite3`; Docker хранит отдельный файл в именованном томе. Их локальные итоги не объединяются, а ledger не показывает расход ключа через gateway account — сверяйте общий расход с кабинетом шлюза. Для совместного учёта процессов в одной среде укажите тот же путь через `--ledger` и одинаковый `budget_scope`.

Флаг `--compare-hackathon` оценивает те же token counts по настроенным тарифам хакатонного профиля в RUB. Оба профиля должны использовать одну модель, а тарифы хакатона должны быть заполнены. Поля `projected_hackathon_cost_rub` и `projected_hackathon_daily_capacity` — расчётное сравнение по тарифам из конфигурации; вызов не резервирует хакатонный бюджет, не выполняет конвертацию и не сообщает фактическую стоимость у хакатонного провайдера. Убедитесь в правильности тарифов перед использованием оценки.

Адреса шлюза хакатона из шаблона входят в список разрешённых config validator. Их текущая доступность и выдача ключа требуют проверки оператором. Адаптер принимает только шесть разрешённых моделей и не поддерживает другой провайдер или модель.

## Тесты

Все тесты запускают mock transport и работают без сети:

```sh
PYTHONPATH=apps/intelligence python -m unittest discover -s apps/intelligence/tests -v
```
