# Статус проверки AI/Data

Срез проверки: 24 октября 2026. Восемь дополнительных сценариев выявили ошибки при проходящих штатных тестах. Исправления включены в обычный набор; исходные независимые acceptance tests также проверены отдельно.

| Сценарий | Исправление | Статус |
|---|---|---|
| Личное скрытие источника | Не меняет основания анализа компании | Проверено |
| Перегрузка API | Безопасный повтор того же запроса после освобождения слотов | Проверено |
| Длинный документ | Полный оригинал, ограниченный анализ, без обрыва задачи | Проверено через API и worker |
| Просроченный сбор | Токен и поколение защищают состояние нового владельца | Проверено |
| Перепечатки | Дословная копия не добавляет группу подтверждения | Проверено |
| Retry-After | Соблюдаются секунды и HTTP-дата без раннего сокращения | Проверено |
| Отмена сбора | Следующий запрос не начинается после отмены | Проверено |
| Общий пакет | Конкурентный разбор не дублирует модельный вызов | Проверено в потоках и процессах |

Полный набор: **352 теста и 11 subtests** на хосте Python 3.14 и в Docker Python 3.12.14. Исходный независимый файл: **8 из 8**. Схемы совпадают с моделями; демо, пять сценариев baseline evaluation и локальный турнир проходят. Новых платных вызовов для исправлений не выполнялось.
