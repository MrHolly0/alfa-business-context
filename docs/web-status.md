# Статус web-приложения

React UI собирается Node.js и работает в nginx-контейнере со статическими файлами. UI показывает локальные демоданные и хранит действия в `localStorage`. PHP Core пока не подключён: `/api/` возвращает `503`. Python AI/Data запускается отдельно и не управляет браузерным демо.

Первым открывается макет входа. Логин и пароль не проверяются, не сохраняются и не отправляются на сервер; кнопка открывает демо в текущей вкладке через `sessionStorage`. Выход возвращает к макету входа. Этот переход не ограничивает доступ к данным на сервере и не заменяет банковскую авторизацию. Главный экран и меню используют общую структуру для всех демонстрационных компаний и показывают только имеющиеся в прототипе сведения, без выдуманного банковского баланса.

Компактные правила в `apps/web/public/compact.css` применяются ко всем разделам: обзору, ситуациям, новостям, профилю компании, формам, исследованию и отчётам. Выбор компании меняет данные и относящиеся к ней вопросы, но использует те же карточки, сетки, навигацию и размеры элементов. На узком экране поля ввода остаются размером 16 px, чтобы браузер не увеличивал страницу при фокусе.

Сквозной офлайн-путь Python запускается командой `demo-data`; он проходит collector, corpus, события и baseline-анализ по локальным фикстурам. `run-task`, внутренний API и worker также находятся в Python; worker требует настроенный Core endpoint. Это не production PHP интеграция. Исторические сведения о перенесённом Node Worker сохранены в [архивном аудите](reference/web-audit.md). Команды — в [infra README](../infra/README.md), схема AI/Data — в [руководстве интеграции](ai-integration.md).
