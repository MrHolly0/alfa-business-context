# Проверка на данных кейса

Запускать на локальном компьютере с Docker Compose и Python 3. Скрипт скачивает оригиналы по ссылкам из брифа, проверяет SHA-256, добавляет данные в Core, распознаёт PDF локально и готовит разрешённые источники. Он не меняет существующий `.env`, старые профили и ключи.

Ключ организаторов задаётся только как `HACKATHON_API_KEY` в локальном `.env` либо в окружении запуска. Не добавляйте его в браузер, JSON-конфиг провайдера или Git. Передача материалов разрешена только через шлюз Альфы.

```sh
sh infra/prepare-judging.sh --allow-organizer-data-to-alfa
```

Вход: http://localhost:4173, `demo@alpha.test` / `DemoAlpha2026!`. Это известная локальная учётная запись; для внешнего стенда создайте отдельного пользователя и передайте его email в `JUDGING_USER_EMAIL` перед подготовкой. Пароль задаётся командой Core `bin/create-user.php` через stdin.

Для сохранённого модельного результата выберите `U_57706`. Также доступны `U_9250` и `U_408263`. На странице обзора нажмите «Проанализировать». Запуск синхронный, до одного события и трёх модельных обращений; интерфейс ждёт настоящий ответ. Core проверяет права, фиксирует версии контекста/источников и после ответа отклоняет устаревший результат. Параллельный запуск той же компании вернёт 409. Это ограниченный HTTP-сценарий, полноценной очереди Core пока нет.

Результат содержит выводы, доказательства, уточнения, ограничения покрытия и фактического провайдера. Наличие текста модели не подтверждает его истинность. `partial` означает, что часть проверки не завершена: например, исчерпаны обращения, нет подходящих доказательств либо источник недоступен. При неизвестном воздействии система не утверждает отсутствие риска.

## Что загружается

- CSV: 85 525 исходных строк компаний, 12 514 связей и 1 380 585 платежных агрегатов. В Core — 85 513 однозначных компаний; 12 конфликтующих строк `U_428697` исключены из профилей, оригинал сохранён. Ссылки на отсутствующих контрагентов сохраняются как исходные идентификаторы, без выдуманных компаний.
- Для анализа подготовлены три профиля из 24 исходных полей с номерами строк и происхождением. Единицы выручки, валюта и периоды платежей не заданы; порог 15 млрд не считается подтверждённым. Платёж не доказывает поставку.
- Девять PDF Альфы сохранены целиком; 64 страницы распознаны Tesseract rus+eng. Восемь материалов имеют дату публикации и доступны в поиске, обзор золота пока ожидает точную дату. Материал о стали — от 15 апреля 2021 года. OCR-цитату нужно сверять с исходной страницей.
- Внешняя лента: пресс-релизы ЦБ `https://www.cbr.ru/rss/RssPress`. Полнота новостного рынка не подтверждена; свободного поиска по всему интернету нет. Дополнительные источники выдаёт Core через source policy.

Сырые CSV, PDF, OCR, bundle и разрешения находятся в игнорируемой `.local/data/case/`. Python хранит аналитические данные в своей PostgreSQL БД и не пишет таблицы Symfony. Core владеет компаниями, членством, контекстом, источниками и опубликованными результатами.

## Провайдер и бюджет

`compose.judging.yaml` включает только профиль `hackathon` из `providers.judging.json`, без fallback на OpenRouter. Все роли используют разрешённую Gemma через основной шлюз Альфы. Разрешение на закрытые материалы связано с точным профилем компании и версиями импортированных документов; посторонние материалы не получают это разрешение автоматически.

Тарифы шлюз не сообщает. Перед каждой попыткой резервируются 10 ₽; неизвестная фактическая стоимость остаётся неизвестной, резерв не освобождается. Общий scope ограничен 500 ₽ за день, 500 ₽ за всё время и 50 попытками. Резерв не гарантирует верхнюю цену запроса; отдельный лимит организаторов — 500 ₽/сутки, сброс в 03:00 МСК. Перезапуск не обнуляет учёт.

## Повторный запуск и остановка

```sh
docker compose -f compose.yaml -f compose.judging.yaml up --build --wait
docker compose -f compose.yaml -f compose.judging.yaml down
```

Не используйте `down -v`, если нужно сохранить данные. Подготовку можно повторять: импорт CSV сверяет все три хеша, PDF не создаёт новую ревизию при прежних оригинале/тексте, существующий контекст пользователя сохраняется. Изменение исходных файлов под прежней версией запрещено.

Тесты без внешних модельных вызовов:

```sh
docker compose --profile test run --build --rm core-test
docker compose --profile test run --build --rm web-test
docker compose --profile test run --build --rm intelligence-test
```
