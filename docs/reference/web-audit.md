# Архивный аудит исходного web-прототипа

> Исторические заметки о версии с Node Worker. Они не описывают текущий runtime, не являются инструкцией запуска и не подтверждают качество или интеграции.


Ниже сохранены заметки о переносе старого Node Worker для исторического контекста. Эти маршруты и детали не описывают runtime текущего checkout.

## Статус перенесённого прототипа

Read-only аудит исходного экспорта и перенесённых файлов. В apps/web перенесены приложение, tests, fixture, assets и исторические docs; dist, служебная конфигурация публикации и старые README/START-HERE исключены. Бизнес-логику и UI при переносе не меняли. Этот документ описывает код, а не подтверждает внешние интеграции, безопасность или исходные материалы кейса.

## Что работало в исходном экспортированном варианте (архивные заметки)

- UI на React 18 и AlfaLab Core Components: каталог ситуаций/событий, фильтры, пагинация, три учебных профиля, локальные действия и история. Состояние в localStorage конкретного браузера (apps/web/src/app.js:85–103, :176–180); банковские роли/права не авторизуются.
- Детерминированные правила релевантности/пересмотра, история оснований, поля профиля и сценарные допущения (apps/web/src/engine.js:211–407, :415–600).
- Исследования дат в интервале 01.04–22.10.2026, coverage, Pearson и лаги 0/3/7/14 дней считают синтетический ряд, генерируемый формулами (apps/web/src/engine.js:612–727). «150 материалов» — генератор вымышленных событий для каталога/пагинации, не архив и не ingest нагрузка (apps/web/src/volume-demo.js:24+).
- Экспорт сводки/печать, CSV исследований, ручной текст и контекстные предложения продуктов работают локально; банковский каталог не запрашивается (apps/web/src/app.js; apps/web/src/bank-products.js:2–45).
- Worker читает две RSS-ленты ЦБ, до 30 публикаций на каждую, объединяет доступные результаты и кэширует минуту в памяти процесса (apps/web/server/index.js:3–14, :195–234, :537–550). Это один издатель, не независимый резерв.
- HTML импорт ограничен allowlist доменов и простым извлечением article/main либо всего тела; метаданные берутся из HTML meta (apps/web/server/index.js:53–71, :236–271). Это не универсальный HTML/PDF парсер.
- Без модели помощник использует правила. С моделью Worker планирует, лексически ранжирует только переданные UI источники, синтезирует, проверяет JSON/ID ссылок и делает максимум один repair (apps/web/server/index.js:273–487). Сервер не подбирает банковский корпус сам; структурная проверка не доказывает истинность.

## API и настройки исходного варианта (не текущие маршруты)

GET /api/status, GET /api/news, POST /api/import ({url}), POST /api/analyze ({question, company, sources}); прочие API-пути — 404. POST требует JSON и проверяет Origin, если тот передан; тело максимум 180 KB. In-memory limiter: 4 analyze/min, 20/min прочих путей (apps/web/server/index.js:488–590).

Worker принимает LLM_BASE_URL, LLM_API_KEY, LLM_MODEL, LLM_CASE_MODEL. Код допускает legacy labels, не все совпадают с именами из брифа (apps/web/server/index.js:25–31), и не проверяет соответствие provider ID разрешённой модели (:273–279). Корневой .env.example не содержит ключ. Node сам .env не читает; Compose использует корневой .env, локально env экспортировать или передать через node --env-file.

## Уточнения к README исходного экспорта

- «Резервный источник» — неточно: обе ленты принадлежат ЦБ.
- «Загрузка официальных HTML» — ограниченный парсер с allowlist, без PDF; дата может быть пустой, RSS URL как статья не принимается.
- Утверждение, что инструмент агентного цикла добавляет банковские материалы, расходится с кодом: ранжируется только присланный браузером список, отдельного поиска нет.
- При сбое Worker сохраняет кэш только в памяти; локально сохранённые источники живут в браузере, серверного устойчивого архива нет.
- 150 материалов — synthetic demo, не подтверждение реального ingest или пропускной способности.
- package 10.0.0, но /api/status возвращает версию 6.0 (apps/web/server/index.js:530–536).

Не подключены банковский SSO/ACL, общая БД/серверная история, фоновые jobs при закрытой вкладке, push, отправка менеджеру, общий учёт бюджета LLM, семантический поиск/граф, полный архив новостей и доказательство причинности. Внешняя доступность зависит от сети.

## Запуск и проверка исходной сборки (историческая запись)

Исходная сборка зависела от пустой служебной конфигурации публикации; эта зависимость удалена из build/validate. Build генерирует Worker ESM со встроенными UI/assets; validate проверяет ESM и default.fetch. Root npm run dev сначала строит артефакт. Специальные hosting-пути не нужны.

Из корня:
- npm ci --prefix apps/web
- npm test
- npm run build
- npm run validate
- npm run dev
- docker compose up --build --wait

Устаревшие численные результаты smoke/test из старой Node Worker сборки удалены: они не относятся к текущему runtime.

Исходный Node Worker не является частью текущего приложения. Текущее AI/Data состояние и job fixtures описаны в [модели данных](../data-model.md) и [контрактах](../../contracts/intelligence/README.md).
