# Ближайшие задачи

В Python работают импорт, поиск, многошаговый анализ, проверка оснований, расходы, внутренний API и worker. Добавлены реестр настроек и отдельный турнир с ручной публикацией и откатом. Тесты и учебный пример работают без модели; это не измерение качества реальных ответов.

| Кто | Следующая задача | Результат для команды |
|---|---|---|
| БА + промпты | Подготовить разрешённые реальные материалы и отложенные примеры для двух компаний/ролей | Ожидаемые выводы, основания и случаи, где влияние не подтверждается |
| Backend | Создать PHP Core, сохранять профиль/задание, реализовать claim/heartbeat/result по контракту | Сквозной путь через настоящий Core, включая отмену и устаревший результат |
| ML | Прогнать выбранную модель на отложенном наборе, провести турнир настроек с ручной разметкой и подтвердить тарифы шлюза | Качество ссылок/выводов, ошибки, расход и время на сценарий |
| Frontend | Подключить экран к Core и показать ожидание, partial/unknown, источники и уточнения | Рабочий пользовательский путь с тем же кандидатом оценки |

[Форматы для Backend](../contracts/intelligence/README.md), [Python-запуск](../apps/intelligence/README.md), [проверки](development.md).

После сквозного прогона — фоновые импорты разрешённых источников, улучшение поиска и проверка полезности рекомендаций. Полный прежний список R-01—R-27 сохранён в [подробном плане](reference/backlog-details.md); это не список уже реализованного.

Автоматическая переработка настроек после критики ещё не реализована. Сейчас критик сохраняет проверяемые замечания; новую версию регистрируют отдельно. Подключение настоящего теневого трафика и доказательство качества на реальных данных также остаются следующими задачами.

Исправлены блокировка очереди одним недоставленным результатом, URL RSS, история метаданных, предел PDF, основания цепочек влияния и неполный вход судьи. Турнир фиксирует активную базовую версию и учитывает повторное использование holdout. Дальше нужны размеченные реальные примеры и смысловая приёмка; общий разбор события для многих компаний, хранение оригиналов и исторический replay ещё не реализованы.
