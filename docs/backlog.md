# Ближайшие задачи

Наша Python-часть реализована: импорт, поиск, многошаговый анализ, проверка оснований, расходы, внутренний API и worker. Тесты и учебный пример работают без модели; это не измерение качества реальных ответов.

| Кто | Следующая задача | Результат для команды |
|---|---|---|
| БА + промпты | Подготовить разрешённые реальные материалы и отложенные примеры для двух компаний/ролей | Ожидаемые выводы, основания и случаи, где влияние не подтверждается |
| Backend | Создать PHP Core, сохранять профиль/задание, реализовать claim/heartbeat/result по контракту | Сквозной путь через настоящий Core, включая отмену и устаревший результат |
| ML | Прогнать выбранную модель на отложенном наборе, настроить prompts и подтвердить тарифы шлюза | Качество ссылок/выводов, ошибки, расход и время на сценарий |
| Frontend | Подключить экран к Core и показать ожидание, partial/unknown, источники и уточнения | Рабочий пользовательский путь с тем же кандидатом оценки |

[Форматы для Backend](../contracts/intelligence/README.md), [Python-запуск](../apps/intelligence/README.md), [проверки](development.md).

После сквозного прогона — фоновые импорты разрешённых источников, улучшение поиска и проверка полезности рекомендаций. Полный прежний список R-01—R-27 сохранён в [подробном плане](reference/backlog-details.md); это не список уже реализованного.
