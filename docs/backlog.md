# Следующие шаги

Python-модуль уже выполняет сбор, сохранение оригиналов и версий, объединение событий, общий разбор, анализ компаний, периоды и наблюдения. Есть настройки аналитика, турнир и worker. Проверки кода и синтетические примеры не подтверждают смысловую точность на банковских данных.

## Подключить продукт

| Кто | Работа | Результат |
|---|---|---|
| Backend | Реализовать Symfony: права, профили, источники, задания, отмену и приём результатов | Настоящий путь Core → Python worker → Core с проверкой версий и устранением повторов |
| Backend + Frontend | Подключить интерфейс к Core, передавать уточнения и показывать состояние задания | Один пользовательский сценарий вместо отдельных UI и Python-демо |
| Аналитик бизнеса | Предоставить разрешённые CSV и банковские материалы, подтвердить единицы и происхождение полей | Контекст компании и источники без догадок по идентификаторам, платежам и группам |
| ML + оператор шлюза | Подтвердить тарифы Альфы и выполнить генерацию в разрешённом бюджете | Проверенный обязательный провайдер, учтённые ошибки, время и расходы |
| Аналитик бизнеса + эксперты + ML | Разметить независимые примеры для компаний и ролей | Оценка обоснованности, пропусков, полезности и затрат; отдельные данные для настройки и проверки |

## Что оценить перед расширением

- Полноту отбора компаний и слабые переходы в цепочках влияния.
- Пользу уточняющих вопросов и пересмотра после ответа пользователя.
- Качество и стоимость моделей на отложенных примерах. Синтетический турнир проверяет механику, но не доказывает улучшение.
- Пригодность источников, условия хранения и актуальность банковских материалов.

Поиск сейчас лексический и ограничен разрешённым корпусом. Обучаемое ранжирование, embeddings, общий поиск по сети и многосерверное хранилище не входят в проверенный запуск. Неизвестные факты компании и финансовые эффекты сохраняются как неизвестность или гипотеза.
