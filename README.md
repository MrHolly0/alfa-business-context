# Бизнес-контекст

Демонстрационный продукт для руководителей крупного бизнеса: связывает новости и внешние события с контекстом компании, показывает источники и помогает решить, что проверить дальше. Он различает подтверждённые сведения компании, позиции банка, выводы модели и неизвестные данные.

## Состав сейчас

| Часть | Каталог | Что работает |
|---|---|---|
| Web | `apps/web` | React-интерфейс: по умолчанию вход в Core, список доступных компаний, профиль, контекст, метрики/обзор, запуск анализа и чтение новостей. Вход в старое браузерное демо выбирается явно. |
| Core | `apps/core` | Symfony 7.4 / PHP: cookie-сессия, пользователи и членство в компаниях, версионируемый контекст, метрики/наблюдения, события, обратная связь, обсуждения, каталог новостных источников и результаты сборов. |
| Intelligence | `apps/intelligence` | Python: сбор, хранение и версии материалов, события, персональный анализ, роли исследователя/аналитика/критика и worker-контракт. Core в текущем новостном пути вызывает внутренний Python API напрямую. |
| Compose | `compose.yaml` | PostgreSQL с отдельными базами и ролями Core/AI, миграции, сервисная авторизация, Core, Python API и web. |

## Запуск

Требуются Docker и Docker Compose. Из корня репозитория:

```sh
docker compose up --build --wait
```

Web: http://localhost:4173. По умолчанию введите локальную seeded-учётную запись `demo@alpha.test` / `DemoAlpha2026!`. Это только для локальной демонстрации, не для публикации или эксплуатации. При первом запуске Compose применяет Core-схему и создаёт учебного пользователя/компанию; ключи моделей не нужны. Можно выбрать «Посмотреть демо», чтобы открыть прежний UI на локальных данных браузера. Остановка: `docker compose down`; обычная остановка сохраняет volumes с базами и файлами.

Новая база содержит учебную компанию, но источники новостей автоматически не добавляются. Подключение источника и плановый baseline-сбор описаны в [демо-инструкции](docs/demo.md). Полный цикл с Core job queue и claim/lease worker пока не реализован.

Для проверки с материалами организаторов и моделями Альфы используйте [инструкцию для судей](docs/judging.md). Она загружает три CSV и девять PDF, готовит три компании и включает отдельный `compose.judging.yaml`. Обычный запуск выше остаётся без внешних модельных обращений.

## Архитектурные границы

React обращается к Core через nginx same-origin `/api/`. Core хранит пользовательское состояние и права в `business_context_core`. Python хранит материалы и аналитические артефакты в `business_context_ai`; у приложений отдельные роли и пароли. Основной расписанный сценарий — PHP-команда Core отправляет разрешённый, ограниченный снимок в Python `/internal/v1/analyze` с сервисным bearer и настроенным tenant `core-local`, затем Core сохраняет результат своего news run. Это прямой вызов ограниченного workflow, а не полноценный Core-owned job claim/heartbeat/result lifecycle.

Провайдерские ключи используются только Python-процессом при явной настройке модели. Демонстрационный режим по умолчанию не требует внешнего LLM. Материалы кейса загружаются отдельной командой в приватный каталог и PostgreSQL. Доступ к AlfaGen и банковскому SSO не подключён.

## Проверки

```sh
npm test
```

Команда запускает изолированные тесты Core, web и Python через Compose test profile. CI также выполняет сборку/валидацию web и проверки Intelligence. Это не подтверждает промышленную пригодность, качество на реальных клиентах или подключение банковских систем.
